# Data types

Every type is a `Dataset` carrying the dimensions inferred from its file. The subtypes differ in which dimensions apply to them.

## Dataset

```python
class Dataset(core: '_core.Dataset') -> 'None'
```

Data of a known kind, carrying the dimensions inferred from it.

### Dataset.applicable

```python
applicable: tuple[str, ...]  # property
```

The dimensions that mean anything for this kind of data.

A dimension outside this set is not a gap to be filled in: asking a
FASTA for its quality encoding is a category error.

### Dataset.contigs

```python
contigs: list[Contig] | None  # property
```

The contigs of the reference this data is on, in file order.

### Dataset.dimension

```python
dimension(self, name: 'str') -> 'DimensionValue | None'
```

One dimension's value, or None if it is unknown or inapplicable.

### Dataset.dimensions

```python
dimensions: Mapping[str, DimensionValue]  # property
```

Every dimension that has a known value, by name.

### Dataset.file

```python
file: str  # property
```

The file this data is, for code that has to open it.

`path` is the honest answer to "where did this come from, if
anywhere?", so it can be `None` — a step's output carries dimensions
worked out before anything ran, and has no file of its own until it
does. This is the answer for the other question, the one a
`lg.write` body asks:

    return lg.write(lambda out: interpret(v.file, out))

Inside that function the steps above have run, so there is a file,
and saying so in the type is what keeps a body from having to prove
it.

#### Raises

| Raises | When |
|---|---|
| `ValueError` | If this data has no file behind it at all. |

### Dataset.kind

```python
kind: str  # property
```

The name of the kind of data this holds.

### Dataset.path

```python
path: str | None  # property
```

The file this was loaded from.

### Dataset.samples

```python
samples: list[str] | None  # property
```

The samples this data covers, in order.

### Dataset.unknown_reason

```python
unknown_reason(self, name: 'str') -> 'str | None'
```

Why an applicable dimension has no value.

None when the dimension is known, or when it does not apply to this
kind of data at all.

## Samples

```python
class Samples(samples: 'list[Reads]') -> 'None'
```

The samples a glob matched, in the order their files appeared.

Iterable, indexable and sized, so it can be used as an ordinary sequence
of `Reads`. `map` is the part the golden example uses.

### Samples.ids

```python
ids: tuple[str, ...]  # property
```

Each sample's identifier, in order.

Taken from the filenames, with any mate marker removed, unless the
reads were loaded with the identifier declared.

### Samples.map

```python
map(self, build: 'Callable[[Reads], T]') -> 'list[T]'
```

Apply a chain of steps to every sample.

Nothing is executed. `build` is called once per sample and returns
whatever the last step in the chain returns — a handle, not data —
so the result is one output per sample, ready for `lg.Pipeline`.

#### Parameters

| Parameter | Description |
|---|---|
| `build` | What to do with one sample's reads. |

#### Returns

One result per sample, in order.

## Contig

```python
class Contig(name: 'str', length: 'int | None', md5: 'str | None') -> None
```

One sequence in a reference.

### Attributes

| Attribute | Description |
|---|---|
| `name` | The name as written: `chr1`, `1`, `K03455.1`. |
| `length` | Length in bases, or None when the file records no length. |
| `md5` | MD5 of the uppercased sequence, as the SAM specification defines `@SQ M5`, or None when neither recorded nor computable. |

## DimensionValue

```python
class DimensionValue(name: 'str', value: 'str', source: 'str') -> None
```

A dimension's value, and where it came from.

### Attributes

| Attribute | Description |
|---|---|
| `name` | The dimension's name, e.g. `reference`. |
| `value` | The value, rendered for a human. |
| `source` | Where it came from, e.g. `from BAM @SQ header: data/x.bam`. This is the part that makes an error actionable. |

## StepOutput

```python
class StepOutput(
    step: 'Step[Any,
    Any]',
    arguments: 'dict[str,
    object]',
) -> 'None'
```

A handle on data a step would produce.

Returned by calling a `Step`. It holds no data and has never touched a
file; what it knows is which step would make it, and from what. Once a
`Pipeline` has been built from it, `dataset` holds the dimensions the
engine propagated — the dimensions the output *will* have, worked out
without running anything.

### Attributes

| Attribute | Description |
|---|---|
| `step` | The step that would produce it. |
| `arguments` | Everything the step was called with, by parameter name. |

### StepOutput.dataset

```python
dataset: Dataset | None  # property
```

The propagated output dataset, once a `Pipeline` has been built.

`None` before that: propagation is the graph's work, and there is no
graph until a pipeline asks for one.

### StepOutput.file

```python
file: str  # property
```

Where the output is, once the step has produced it.

The same name `Dataset.file` has, because a body cannot tell which
it was handed: a step's input is loaded data for the first step of a
pipeline and another step's handle after that. A `lg.write` body
reads it inside the function it hands back, by which time the engine
has run whatever comes above it:

    return lg.write(lambda out: interpret(v.file, out))

#### Raises

| Raises | When |
|---|---|
| `RuntimeError` | Before the step has run, when there is no file to name. A shell command should use `{placeholders}` instead, which the engine fills in for it. |

### StepOutput.inputs

```python
inputs(self) -> 'tuple[tuple[Parameter, object], ...]'
```

The data arguments, paired with the parameters they filled.

### StepOutput.kind

```python
kind: str  # property
```

The kind of data the step declares it produces.

## Written

```python
class Written(
    function: 'Callable[[Path],
    Iterable[Noticed] | None]',
) -> None
```

A step whose work is Python, and writes its own output.

### Attributes

| Attribute | Description |
|---|---|
| `function` | Called with the path to write to, once the engine has decided what that path is. It may return what it noticed about its own work, as `Noticed` pairs. |
