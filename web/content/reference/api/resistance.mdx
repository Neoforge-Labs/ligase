# Resistance interpretation

Turning variant calls into HIV-1 drug-resistance calls. The scoring engine reproduces 3,348 published Stanford expectations exactly; see [validation](/project/validation/).

Positions must be in **whole-genome HXB2 K03455 coordinates**. A *pol*-relative reference is read as though it were whole-genome and the gene windows land on the wrong genes, silently -- see [the SAWA evaluation](/project/in-use/sawa/).

## ResistanceReport

```python
class ResistanceReport(core: '_core.Dataset') -> 'None'
```

An interpreted drug-resistance report.

### ResistanceReport.applicable

```python
applicable: tuple[str, ...]  # property
```

The dimensions that mean anything for this kind of data.

A dimension outside this set is not a gap to be filled in: asking a
FASTA for its quality encoding is a category error.

### ResistanceReport.contigs

```python
contigs: list[Contig] | None  # property
```

The contigs of the reference this data is on, in file order.

### ResistanceReport.dimension

```python

```

One dimension's value, or None if it is unknown or inapplicable.

### ResistanceReport.dimensions

```python
dimensions: Mapping[str, DimensionValue]  # property
```

Every dimension that has a known value, by name.

### ResistanceReport.file

```python
file: str  # property
```

The file this data is, for code that has to open it.

`path` is the honest answer to "where did this come from, if
anywhere?", so it can be `None` — a step's output carries dimensions
worked out before anything ran, and has no file of its own until it
does. This is the answer for the other question, the one a
`lg.write` body asks:

    return lg.write(lambda out: interpret(v.file, out))

Inside that function the steps above have run, so there is a file,
and saying so in the type is what keeps a body from having to prove
it.

#### Raises

| Raises | When |
|---|---|
| `ValueError` | If this data has no file behind it at all. |

## hivdb.interpret

```python
interpret(
    variants: 'Variants',
    reference: 'Reference',
    *,
    coverage: 'Alignment | None' = None,
    algorithm: 'str' = 'HIVDB_9.8',
    mixture: 'float' = 0.15,
    depth: 'int' = 100,
) -> 'ResistanceReport'
```

Score a sample's variants against a vendored resistance algorithm.

### Parameters

| Parameter | Description |
|---|---|
| `variants` | The calls to interpret. |
| `reference` | The reference they were called against. Required: codons cannot be assembled without it. |
| `coverage` | The alignment the calls came from. Without it no position can be known to be unread and no codon can be phased, and the reading notes both assumptions -- which the run report then says and `pipe.run()` carries on the step's `notes`. |
| `algorithm` | Which vendored algorithm to use, from `ALGORITHMS`. |
| `mixture` | The fraction of reads an allele must reach to count as present. Where both the reference and an alternate reach it the codon holds both amino acids, exactly as an ambiguous base does to Stanford's own interpreter -- taking the majority instead would discard the minority resistance that deep sequencing exists to find. With an alignment it also decides which *combinations* of those alleles are real: a VCF says what is at each position and not what travels together, so reads spanning a codon are counted as the triplets they carry and the codon holds the amino acids reaching this fraction of them. |
| `depth` | The depth a position must reach to count as read. A codon whose bases do not all reach it is reported as unread rather than as reference. |

### Returns

A recipe, typed as the report the step declares.

### Raises

| Raises | When |
|---|---|
| `ValueError` | If `algorithm` is not one the engine ships. The error names the ones it does. |

## hivdb.fingerprint

```python
fingerprint() -> 'str'
```

What the vendored algorithms are, by version, date and content.

This is what a step declaring `tool="hivdb"` records as its tool
version, so it is what puts the rules into the cache key. It names
every vendored algorithm rather than only the one in use, because the
engine probes versions before any step body has said which it wants.

### Returns

A line naming each algorithm, its version, its date and the BLAKE3
of its rules.
