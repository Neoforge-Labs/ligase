## The vendored resistance algorithm

`crates/ligase-core/rulesets/` holds Stanford's HIVdb algorithm definitions,
unmodified and pinned by SHA-256. They come from
[`hivdb/hivfacts`](https://github.com/hivdb/hivfacts), which carries the
**Unlicense** — a dedication to the public domain — so redistributing them
here is unencumbered.

Neither `hivdb/sierra` (GPL-3.0) nor `hivdb/asi_interpreter` (Apache-2.0)
contributed any code to Ligase. The licence, the provenance of each file and
the citation Stanford asks for are recorded in
[`rulesets/README.md`](https://github.com/Neoforge-Labs/ligase/blob/main/crates/ligase-core/rulesets/README.md).
