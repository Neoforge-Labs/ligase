# How Ligase is built

<Lede>
One page per component, each describing how it is put together, which design
decisions it rests on, and what those cost. These are internals: where a page
here has a user-facing counterpart in [concepts](/concepts/), it says so and
links to it.
</Lede>

Almost none of this is reachable from Python. The correctness-critical
logic — deciding whether two files mean the same thing, whether two dimensions
agree, whether a step may be skipped — lives in Rust with no `pyo3` in the
module, and is exposed through the binding crate as a narrow surface.
